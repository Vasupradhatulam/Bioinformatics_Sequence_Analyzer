# 🧬 Bioinformatics Sequence Analyzer

A Python-based bioinformatics tool for analyzing DNA sequences from FASTA files.

## 📌 Project Overview

The Bioinformatics Sequence Analyzer is a computational biology project developed using Python. It processes DNA sequences and extracts important sequence-level information through automated analysis and visualization.

## 🔬 Features

- FASTA file processing
- DNA sequence length calculation
- Nucleotide composition analysis
- GC and AT content calculation
- Window-based GC content analysis
- DNA motif searching
- Reverse complement generation
- Open Reading Frame (ORF) detection
- DNA-to-protein translation
- Amino-acid composition analysis
- Data visualization

## 🧪 Analysis Workflow

FASTA Input

## 📊 Example Results

The analyzer was tested using a *Homo sapiens* DNA sequence.

- Sequence length: 125,833 bp
- GC content: 44.10%
- AT content: 55.90%
- DNA motifs were identified and their positions were reported.
- Potential ORFs were detected and translated into protein sequences.
- Amino-acid composition was visualized using Python.
